### 1. 项目定性

本项目（下称「本软件」）是一个**基于 Web Audio API 的音频合成与音效研究工具**，用于：

- 音频工程、DSP、Web Audio API 的学习与实践；
- 扬声器、耳机、低频响应的主观测试；
- 影视、游戏、舞台等场景的**音效素材研究与合成实验**；
- 个人娱乐。

**本软件不是警报器，不是执法设备，不是特种车辆配件，也不具备任何现实中的警示、开道、执法、救援功能。** 本软件输出的所有声音均为**软件合成音或内置采样**，与任何真实执法机构、应急部门无任何关联、无任何授权、无任何背书。

### 2. 允许的用途

- 在**私人空间**（如自己的房间、录音棚、实验室）内，以**他人不可闻及**的音量进行学习、测试与娱乐；
- 在**音频制作软件**中作为参考音源，进行合法的音效设计与研究；

### 5. 健康与设备风险

- **听力损伤**：长时间、大音量收听任何声音（尤其是警报音与低频脉冲）可能造成**不可逆的听力损伤**。请控制音量与时长，避免长时间佩戴耳机使用。
- **设备损坏**：本软件包含**低频脉冲（Howler）与低频合成音**，其能量集中在 30–200 Hz。手机、平板、笔记本的内置扬声器**通常无法承受持续低频输出**，可能出现破音、失真甚至**扬声器永久损坏**。请勿长时间满音量播放，使用外接音箱时请确保其支持对应频段。
- **突发音量**：部分音效在启动瞬间存在**瞬态峰值**，可能惊扰他人或宠物，请提前注意环境。

**上述风险由使用者自行评估并承担。**
